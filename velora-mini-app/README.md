# VELORA Telegram Mini App MVP

Telegram Mini App concept for VELORA — nuts, dried fruits and oriental desserts.

## Features
- Home screen
- Product catalog
- Product cards
- Cart
- Order checkout placeholder
- Gift sets
- Telegram-friendly mobile UI

Design: Modern Oriental Premium (cream background, nut brown, gold accents).

Based on the initial project document: VELORA Telegram Mini App Project.
